# PROJECT.md - Animarr

## High-Level Description

Animarr is a specialized anime-focused fork of Sonarr, a PVR (Personal Video Recorder) for Usenet and BitTorrent users. Animarr adapts the Sonarr platform to be tailored specifically for anime content management.

## Goals

### Phase 1: Visual Rebranding (Current)
- Replace all Sonarr branding with Animarr
- Redesign logos, icons, favicons
- Update color palette to anime-themed violet/magenta/pink
- Update browser titles, headers, sidebars
- Maintain full compatibility with Sonarr backend

### Future Phases
- Anime-specific metadata integration (MAL, AniList, Kitsu)
- Anime season/calendar views
- Japanese voice actor/character tracking
- Opening/Ending theme tracking
- Anime-specific quality profiles
- Batch anime release management

## Scope

### In Scope (Phase 1)
- UI branding (logos, icons, favicons)
- Browser title and meta tags
- Header and sidebar branding
- Visible text labels
- Color palette and theme
- Documentation

### Out of Scope (Phase 1)
- NzbDrone namespaces
- Database structure
- API routes
- Backend behavior
- Update mechanism
- Existing functionality
- Search/download logic
